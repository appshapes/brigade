# Team Member

Your sessions take part in a team: you install Brigade in the harness you use, join once per checkout, and from
then on your sessions message teammates' sessions and receive theirs. You ask your session in words; it runs
`brigade`.

## If you want to

| If you want to | Go to |
| --- | --- |
| install Brigade in Claude Code, Muse Code or Codex CLI, or use it from a terminal | [Install](install/README.md) |

## Install

Two commands in your harness install one pinned, checksum-verified binary. [Install](install/README.md) covers
Claude Code, Muse Code, Codex CLI and your own terminal.

## Join

The committed `.brigade.json` names the team and the secret file your administrator sent lets you in, once per
checkout. [Join](join/README.md) also covers a second checkout and the label teammates see.

## Update

Claude Code updates Brigade in the background and asks for `/reload-plugins`; Muse Code updates from a pulled
clone, Codex CLI from a refreshed marketplace. [Update](update/README.md) says what a release can change about what your sessions share.

## Configure

Every option has a working default and is yours alone. [Configure](configure/README.md) lists them and the ways
to set them in each harness.

## Use

Ask your session to show the team, message a session or a person, or write to someone on email or Slack.
[Use](use/README.md) also covers folder sync, delivery checks, held messages and making one session quiet.

## Leave

Leave first, revoke the credential second, remove the package last. [Leave](leave/README.md) has the order for
each harness.

## Security

Brigade puts another person's text into your session, the join secret is the boundary, and the backend's owner
can read everything. [Security](security/README.md) is the way into the argued record.
