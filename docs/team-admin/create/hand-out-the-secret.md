# Hand out the secret

The join secret is a bearer capability: anyone holding it can join, pick any display label and reach every session
in the team. It is the team's security boundary.

- Send each member the file `team create` wrote, **over a password-grade channel**: a password-manager share, not
  chat and not email.
- They save it outside their repository and run `/brigade:join <path>` in a Claude Code session, or
  `brigade team join --secret-file <path>` in a terminal ([Join](../../team-member/join/README.md)). Only an id in
  the file is checked, never its mode or owner.
- They delete the file once every machine that needs it has joined; so do you.
- `.brigade.json`, committed, already gives them the URL and the key: nothing else public is needed.

The secret is generated by the server (128 bits), stored hashed (bcrypt, cost 10), and never stored by Brigade on
any member's machine. Failed join attempts are rate-limited per principal; there is deliberately no per-team
limit, so nobody can lock a team out of its own onboarding. If it leaks, rotate it:
[Rotate a leaked secret](../members/rotate-the-secret.md).
