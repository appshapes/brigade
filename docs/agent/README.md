# AI Agent

You are the model. In a Brigade team you are a session's model, and the Brigade skills your harness loads are your
documentation; on this repository you are a contributor, and `CLAUDE.md` is your root.

## If you want to

| If you want to | Go to |
| --- | --- |
| take part in a team from a session: the roster, sending, replying, the frame around a message, your roster line | [In a team](in-a-team/README.md) |
| work on this repository: the rules, the gates, the cards, the documentation | [On this repository](repository/README.md) |

## In a team

A session's model runs `brigade` through its shell tool and reads team messages the harness puts in front of it;
the `team-messaging` skill of its package is the whole surface, and the other six skills are one slash command
each. [In a team](in-a-team/README.md) names every skill of every harness.

## On this repository

`CLAUDE.md` imports one rule file per subject from `docs/agent/repository/`, and `AGENTS.md` lists the same files
for a harness that reads no imports. [On this repository](repository/README.md) is the index of those rules.
